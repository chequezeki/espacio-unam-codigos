# Código de conducta

Este espacio es de toda la comunidad UNAM. Para que siga funcionando:

- **Respeto.** Sin insultos, acoso, discriminación ni contenido sexual o violento.
- **No borrar ni sustituir** códigos ajenos; cada quien agrega los suyos.
- **Sin spam.** Un código repetido muchas veces satura a todos.
- **Privacidad.** No publiques datos personales tuyos ni de nadie (redes, teléfono, número de cuenta, dirección).
- **Sin ventas ni estafas.** No se intercambian códigos por dinero.

Quien mantiene el repositorio puede borrar aportes, cerrar issues y bloquear cuentas que incumplan estas reglas.
Para reportar algo, abre un [reporte](../../issues/new?template=reporte.yml) o escribe a quien administra el repositorio.
